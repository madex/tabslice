TabSlice Drop-Ordner (scores/)
==============================

Lege einfach beliebige Guitar-Pro-Dateien (.gp, .gp3, .gp4, .gp5, .gpx, .gp7, .gp8),
MusicXML (.xml, .musicxml, .mxl), Capella (.cap) oder alphaTex (.tex) in diesen Ordner.

Jede Datei wird automatisch erkannt und bekommt sofort einen eigenen Embed-Link:
  scores/mein-riff.gp5  ->  /slices/mein-riff/embed/

Alternativ kannst du Dateien auch direkt im Browser ueber "Slice erstellen" hochladen.
